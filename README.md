Бенчмарк для мультиагентных систем: воспроизводимый эффект «роста и падения когнитивных способностей» при смене социальной структуры
Почему это полезно для R&D и мультиагентных систем
Бенчмарк кооперации. В эгалитарном режиме «выживает» тот, кто лучше договаривается и распределяет ресурсы. Это среда, где кооперация становится эволюционно выгодной стратегией.
Тест адаптации к смене правил. Переход к иерархии — это резкая смена функции приспособленности. Можно измерять, насколько быстро агенты перестраивают стратегии, сохраняют ли навыки кооперации или начинают полагаться на близость к лидеру.
Интерпретируемость. Механизм полностью прозрачен: рост когнитивных способностей → рост потребления ресурсов → штраф при дефиците; появление иерархии → перераспределение приспособленности → снижение среднего когнитивного уровня. Это позволяет не только обучать агентов, но и объяснять их поведение.
Воспроизводимость. Модель реализована на Python, все параметры явно заданы, результаты повторяются при одинаковых начальных условиях.
Ключевые параметры и сценарии проверки
Параметр	Описание	Значение в приведённом примере
resource_level	Уровень ресурсов в среде	1.0 (норма)
has_alpha	Социальная структура	False (1–15), True (16–20)
beta_cog_reduction	Коэффициент структурного снижения когнитивного потенциала в подгруппах (технический параметр для стабильной симуляции иерархии)	0.1
brain_cost_factor	Стоимость мозга: сколько ресурсов потребляет единица когнитивных способностей	0.8
Сценарии, которые можно тестировать:

Рост когнитивных способностей: эгалитарный режим + нормальные ресурсы → тренд вверх.
Снижение когнитивных способностей из‑за иерархии: переход к иерархии при норме ресурсов → тренд вниз (как в примере выше).
Эффект дефицита ресурсов (аналог кейса Флореса): эгалитарный режим + дефицит ресурсов (resource_level=0.6) → снижение когнитивных способностей даже без появления иерархии.

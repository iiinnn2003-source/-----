# Эволюционная симуляция когнитивных способностей агентов

Воспроизводимая агент-ориентированная модель (ABM), демонстрирующая фазовый переход среднего когнитивного уровня популяции при смене социальной структуры (от эгалитаризма к иерархии).

## Описание модели

Модель иллюстрирует гипотезу о том, что рост "размера мозга" (когнитивных способностей) обусловлен необходимостью согласования интересов в группе без лидера. Появление формального лидера ("альфы") снижает селективное давление на интеллект рядовых агентов ("бет"), перераспределяя ресурсы в пользу близости к центру принятия решений.

**Ключевые метрики:**
*   **avg_cog**: Средний уровень когнитивных способностей популяции.
*   **mode**: Текущий социальный режим (`Эгалитаризм` / `Иерархия`).

При запуске скрипта четко видно падение среднего `avg_cog` в момент активации режима иерархии, несмотря на неизменный общий уровень ресурсов в среде.

## Технологический стек

*   **Python >= 3.9**
*   **NumPy**: Используется для векторизации вычислений стоимости ресурсов (высокая производительность).
*   **Dataclasses (frozen=True)**: Гарантия иммутабельности состояния агентов (принципы функционального программирования).

## Быстрый запуск (Standalone)

Если вы хотите просто проверить работу алгоритма локально без контейнеризации:

1.  Убедитесь, что установлен [Python](https://www.python.org/).
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите симуляцию:
    ```bash
    python agent_sim_ref.py
    ```
4.  Результаты будут сохранены в папку `outputs/simulation_log.json`.

## Запуск через Docker (Корпоративный стандарт)

Рекомендуемый способ запуска для обеспечения полной воспроизводимости среды. Контейнер изолирует все зависимости версий библиотек.

### Шаг 1: Создание Dockerfile

Создайте в корневой папке проекта файл с именем `Dockerfile` (без расширения) со следующим содержимым:

```dockerfile
# Используем официальный легковесный образ Python
FROM python:3.11-slim

# Установка системных зависимостей (если понадобятся дополнительные пакеты)
RUN apt-get update && apt-get install -y --no-install-recommends gcc && \
    rm -rf /var/lib/apt/lists/*

# Установка рабочей директории внутри контейнера
WORKDIR /app

# Копирование файлов приложения и зависимостей внутрь образа
COPY requirements.txt .
COPY agent_sim_ref.py .

# Установка зависимостей Python
RUN pip install --no-cache-dir -r requirements.txt

# Команда, которая выполнится при старте контейнера
CMD ["python", "./agent_sim_ref.py"]
